# Canvas System

The canvas is the visual workspace where machines are designed.

---

# Canvas Features

• drag-and-drop devices
• port visualization
• cable drawing

---

# Zoom Levels

Zoom controls diagram detail.

Zoomed Out:

Harness level.

Medium Zoom:

Cable level.

Close Zoom:

Individual wires.

• collision avoidance
• path optimization
