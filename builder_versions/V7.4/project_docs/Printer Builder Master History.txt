PRINTER BUILDER PROJECT — MASTER HISTORY LOG
===========================================

PROJECT NAME:
Printer Builder (Modular Machine Design System)

CURRENT VERSION:
V7.3 (Interactive Core - In Development)

CORE PURPOSE:
A visual engineering tool to design machines (starting with 3D printers) using:
- hardware database
- connector-aware boards
- wiring graph system
- SVG visualization
- diagnostics engine
- AI-style feedback system ("Jarvis")

------------------------------------------------------------
HIGH LEVEL ARCHITECTURE
------------------------------------------------------------

System is built on 5 core layers:

1. UI Layer
   - Device selection
   - Add/remove hardware
   - View system state

2. Machine State Layer
   - Stores active devices
   - Stores connections
   - Represents current machine build

3. Hardware Database Layer
   - JSON-based hardware definitions
   - Boards, sensors, motors, cooling systems
   - Expandable without code changes

4. Graph Engine Layer
   - Converts devices into relationships
   - Tracks required dependencies
   - Builds machine structure

5. Visualization Layer (SVG)
   - Board diagrams
   - Connector display
   - Wiring visualization
   - Future: zoom + click interaction

------------------------------------------------------------
HARDWARE MODEL
------------------------------------------------------------

Devices contain:
- name
- type
- required components
- connectors
- pin definitions
- voltage requirements

Example:
Hotend requires:
- heater
- thermistor
- cooling fan

------------------------------------------------------------
CONNECTOR SYSTEM
------------------------------------------------------------

Each board exposes connectors:

Example (Octopus V1.1):
- MOTOR0 (A+, A-, B+, B-)
- HE0 (heater output)
- TH0 (thermistor input)
- FAN0 (PWM fan output)

Each connector has:
- pin count
- signal type
- voltage expectations

------------------------------------------------------------
DIAGNOSTICS ENGINE
------------------------------------------------------------

System checks:
- missing required components
- incompatible wiring
- missing sensors
- unsafe heating conditions

Outputs:
- INFO
- WARNING
- ERROR
- SUGGESTION

Future enhancement:
- Jarvis personality layer

------------------------------------------------------------
JARVIS FEEDBACK SYSTEM (PLANNED)
